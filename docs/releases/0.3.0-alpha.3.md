# Podcast Player 0.3.0-alpha.3

This pre-release makes the companion dashboard card part of the integration itself, so the backend and frontend are installed and updated as one HACS package.

## Highlights

- HACS now installs and updates the integration and companion card together.
- Fresh installations need no JavaScript copy under `config/www` and no Lovelace resource entry.
- Home Assistant serves the bundled card from a versioned integration URL and registers it through the supported frontend module API.
- Storage-mode upgrades automatically remove only exact legacy Podcast Player resource URLs after the bundled module is active.
- YAML-managed resource configuration is never edited automatically; Home Assistant logs a targeted reminder instead.
- The card shows a clear recovery message if a browser ever loads a card version that does not match the backend.
- Diagnostics report privacy-safe card registration and migration status.

## Updating

1. Update Podcast Player through HACS.
2. Restart Home Assistant.
3. Reload the Podcasts dashboard once on each client.

If dashboard resources are managed through the Home Assistant UI, the old Podcast Player resource is removed automatically. If resources are managed in YAML, remove the old Podcast Player card resource from YAML after upgrading.

An old manually copied `config/www/podcast-player-card` directory is no longer used and can be removed after the bundled card is confirmed working.

- 15 browser lifecycle and session tests pass.
- Ruff, Python compilation, JavaScript syntax validation, and the release-package check pass locally.
- Home Assistant configuration validation passes on the live installation.
- A live upgrade from `0.3.0-alpha.2` removed the exact legacy storage-mode resource, served the bundled card with the expected hash, advertised the versioned module, and rendered the existing Podcasts dashboard without a missing-card or version-mismatch warning.

## Recovery

If the card reports that the update is incomplete, restart Home Assistant and reload the dashboard. The warning includes both detected versions so stale browser caching is immediately visible.
